## Deskripsi Game

Game Koin Angka/Gambar merupakan permainan sederhana berbasis bahasa C++ menggunakan library NCurses.

Pemain diminta memilih salah satu sisi koin, yaitu ANGKA atau GAMBAR. Kemudian komputer akan mengacak hasil lemparan koin. Pemain dinyatakan menang apabila pilihannya sesuai dengan hasil koin.

## Fitur Permainan

1. Mulai permainan.
2. Petunjuk permainan.
3. Pengacakan hasil koin.
4. Tampilan terminal berwarna.
5. Keluar dari permainan.

## Teknologi

- Bahasa pemrograman: C++
- Library: NCurses
- Compiler: MinGW GCC
